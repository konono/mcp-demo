## Issue 1: 本セッションで新たに発生した問題はなし

### 症状
N/A — 今セッションで実行したコマンドはすべて初回で成功した。前セッション (dd86561f) の Issue 2（`mise x -- python` が `No version is set for shim: python` で失敗）は、本セッションの対応により解消を確認した。

### 影響
N/A

### 原因候補
N/A

### 切り分け
前セッション Issue 2 の解消確認のみ実施: `mise use python@3.12` 後に
`mise x -- python search_demo.py "asyncio" -s wikipedia -n 1 -f text` を実行し、
エラーなく検索結果が出力されることを確認した。

### 実際の原因
前セッション Issue 2 の真因は「マシンに Python が無い」ではなく
「mise.toml にもグローバルにも使用バージョンが設定されていない」だった（本セッション Finding 1 参照）。

### 解決策
`mise.toml` に `python = "3.12"` を追加する。

### 解決確認
`mise x -- python search_demo.py ...` が `query: asyncio  (1 results)` と
Wikipedia の結果 1 件を出力した。シムエラーは発生しなかった。

### 再発防止
プロジェクトで使うランタイムは mise.toml に明示的に記載する。
`mise use <tool>` でツールを 1 つだけ入れると、他に必要なランタイムが
暗黙に不足したままになることがある。
